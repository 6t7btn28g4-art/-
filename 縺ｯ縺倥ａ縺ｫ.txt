西条酒蔵めぐり｜GitHub Pages開始画面維持・表示修正版

【これが重要】
ZIPファイル自体はGitHubにアップロードしません。まずZIPを解凍します。

【アップロード手順】
1. ZIPを解凍します。
2. GitHubの ud-summer リポジトリを開き、main ブランチの一番上（リポジトリ直下）を表示します。
3. Add file → Upload files を選びます。
4. 解凍したフォルダの中身をアップロードします。フォルダごと入れ子にしないでください。
5. GitHubの一覧で index.html、compact-ui.css、compact-ui.js、assets フォルダが同じ階層に並んでいることを確認します。
6. Commit changes で保存します。
7. Settings → Pages で、公開元を main ブランチ / (root) に設定します。
8. 公開後、 https://6t7btn28g4-art.github.io/ud-summer/公開チェック.html を開き、ファイルがOKになるか確認します。

【表示されない場合】
・index.html だけをアップロードしても画像や地図素材は表示されません。assets フォルダを含めてアップロードしてください。
・HTMLやCSSのファイルを新しいフォルダの中に入れると、Pagesの公開先から見つからない場合があります。
・公開チェックでNGになった項目名と結果を教えてください。

この版では、最初に出る開始画面を残しました。ロゴと水紋の演出が表示され、通常は約2.35秒でトップページへ進みます。右上の「スキップ」で早く進むこともできます。開始画面が止まらないよう独立したタイマーも追加しました。文字サイズ・コントラスト・言語などの設定はサイト内の「使いやすさ」から開けます。主要CSS・JavaScriptはHTMLにも内蔵し、GitHub Pagesの /ud-summer/ 配下でも使いやすい相対パスにしています。地図タイルやWebフォントなど一部は外部通信を利用します。


【地図が表示されない場合の案内】
この版では地図の初期化順を修正しています。地図サービスに接続できない場合は、画面に代替の案内と酒蔵一覧へのリンクを表示します。最新のフォルダ内のファイルをまとめてアップロードし、index.html と map.html がリポジトリ直下にあることを確認してください。
